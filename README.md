# Roman & Aizhan 💕

Личный сайт для двоих: таймер до встречи, два острова которые оживают от записей, дневник и вопросы дня.

---

## Шаг 1. Supabase

1. Зайди на [supabase.com](https://supabase.com) → New project
2. SQL Editor → New query → вставь содержимое `supabase_setup.sql` → Run
3. Project Settings → API → скопируй **Project URL** и **anon public key**

## Шаг 2. Фоновая картинка

Положи файл фона с именем `bg.jpg` в папку `public/`. Используй AI-картинку с Нью-Йорком и Астаной.

## Шаг 3. GitHub

Создай репозиторий и загрузи все файлы (кроме `node_modules`).

## Шаг 4. Vercel

1. [vercel.com](https://vercel.com) → Add New → Project → выбери репозиторий
2. Environment Variables — добавь два значения:
   - `VITE_SUPABASE_URL` → твой Project URL
   - `VITE_SUPABASE_ANON_KEY` → твой anon key
3. Deploy

## Первый вход

При первом открытии сайта появится экран настройки — вводите имена, города и дату встречи. После сохранения сайт готов к использованию.

## Остров

- Каждая запись в дневнике добавляет новый элемент на острова
- После 30 записей мост между островами достраивается
- На острове Айжан растут цветы, домик, бабочки
- На острове Романа — деревья, костёр, птицы
